# Proposals

Specs in this folder describe features that **haven't been built yet**. They use the same `YYYY_MM_DD_NNN_SHORT_NAME.md` naming and `## Core/shell impact` section as specs in `docs/`. They're ideas and designs, not a description of how the app works today.

When a proposal is implemented, move it up to `docs/` and update it to match what was actually built.
