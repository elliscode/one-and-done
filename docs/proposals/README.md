# Proposals

Specs in this folder describe features that **haven't been built yet**. They use the same `YYYY_MM_DD_NNN_SHORT_NAME.md` naming and `## Core/shell impact` section as specs in `docs/`. They're ideas and designs, not a description of how the app works today.

When a proposal is implemented, move it up to `docs/` and update it to match what was actually built.

| Proposal | Summary |
|---|---|
| [Observatory-keyed dice](2026_10_15_003_OBSERVATORY_KEYED_DICE.md) | Key the dice stream from The Observatory's random bytes, with a local fallback. |
| [Branching scene navigator](2026_10_17_004_BRANCHING_SCENE_NAVIGATOR.md) | Mark which scenes come next, so the DM's scene list highlights the likely next stops. |
| [Pronoun picker](2026_10_17_005_PRONOUN_PICKER.md) | Optional pronouns for players and heroes, used in place of repeated names. Default is no pronouns. |
| [Handouts and built-in adventures](2026_10_17_006_HANDOUTS_AND_BUILT_IN_ADVENTURES.md) | A Handouts tab for text and image notes the DM reveals to players, plus scenes, handouts and adventures shipped in git. |
